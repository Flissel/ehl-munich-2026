# Plan: Torque without hardcoded content — data from the Dataset, texts from agent + RAG, Nordi on RAG

Branch `feat/ehl-demo-visu` (PR #7 into `feat/ehl-demo-content`). Owner: yunes-mahan. Date: 2026-10-10.

## Goal

1. Bring in the market MCP and the research agent (`main`: `market/`, `research/`) and the RAG backend
   (`feat/ehl-search`: `src/rag_backend`, `scripts/*chunk*|embed*|ingest*`).
2. Torque (`demo/torque/dist/index.html`) shows no hand-written content and no invented numbers:
   numbers come from `Dataset/` (via scripts), texts are generated by the agent with RAG and stored in the vault.
3. Nordi (Torque's copilot) answers with RAG retrieval over the whole Dataset.

## Decisions (2026-10-10, yunes-mahan)

| Topic | Decision |
|---|---|
| Numbers without a Dataset source (competitor scores/prices, feature costs, segments and elasticities, feasibility, ranking weights) | PM-editable **assumption notes** in the vault, labelled as assumptions in the UI. Later, if time allows: the agent researches them via the ehl-market MCP with citations |
| Generated texts | **Batch** per model × market, stored as editable vault notes; Torque reads them; a per-driver "regenerate" calls the Rowboat model + RAG live |
| Qdrant | **WSL + Docker** (`docker-compose.qdrant.yml`), as WP3 designed |
| Scope | All phases tonight, each pushed separately so every step is demo-safe |

## Inventory: what Torque hardcodes (built page, 2026-10-10)

| Block | Kind | Target |
|---|---|---|
| `BMW` | Dataset aggregates, baked into the page | Generated file `dist/data/bmw.json` from `Dataset/` + `research/findings`, loaded at runtime |
| `REQS` texts (title, motive, attr, target, accept, assume, cs, conflict) | Hand-written, 21 drivers | Agent + RAG → `Requirements/` notes + `dist/data/texts.json` |
| `FEAT` (successor feature per driver), `RESEARCH`, `NORDI` intro, `TOUR` | Hand-written | Agent + RAG (FEAT, tour, intro); RESEARCH → findings / assumption notes with sources |
| `REQS` numbers (`feas`, `cn` weights), `MODEL_EXTRA`, `RIVALS`, `SIMF`, `SEGS`/`SEG_MK`/`SEG_ADJ`/`BETA`/`GAMMA`/`SHARE0`, `DERIVED`/`PRESETS` | Invented parameters | `Assumptions/` notes (editable, labelled), synced to `dist/data/assumptions.json` |
| `CARP`, successor specs in `FEAT` (kWh, wheelbase) | Invented | Option-list technical values (`outputs/markdown/options`) where present, else assumptions |
| View names, buttons, method definitions (`FACT`, `KANO_D`, `SRC_D`, `BASIS`), `GEO` map shapes | UI wording / geometry | Stay |

## Phases

### 0. Bring in and run (setup)
- Merge `origin/main`, then `origin/feat/ehl-search` into `feat/ehl-demo-visu`; drop committed `__pycache__`.
- `research/`: copy `Dataset/` to `research/data/raw` (gitignored), `prepare_data.py`, `build_findings.py`.
- `market/`: venv, `pip install -e .[dev]`, pytest; register `ehl-market` in `~/.rowboat/config/mcp.json`.
- RAG: `search/.env` (OPENAI_API_KEY, never committed), Docker Qdrant (after WSL), `chunk_markdown.py`,
  `ingest_qdrant.py`, serve `uvicorn app:app --port 8100` (8000 = visu_pro Unreal backend), CORS for
  `http://torque.apps.localhost:3210`.

### 1. Nordi on RAG
- Torque copilot: before each answer, `POST :8100/search` with the question and filters (model, market);
  put the hits (text, source file, section) next to the existing JSON context; the Rowboat model answers,
  citing sources. RAG offline → today's behaviour plus a visible "RAG offline" note.
- Verify: three questions per model/market, answers cite RAG sources; RAG stopped → graceful fallback.

### 2. Data only
- `demo/visu/torque_data.py`: builds `bmw.json` (the `BMW` structure) from `Dataset/` + `research/findings`,
  compared against the baked block (same keys and counts) before switching.
- Torque loads `data/bmw.json` at start; the baked block is removed.
- `Assumptions/` notes (one per parameter group) + sync → `assumptions.json`; Torque reads them and marks
  them "assumption" wherever shown.

### 3. Generated texts
- `demo/visu/generate_texts.py`: per model × market and driver, retrieve with RAG (+ findings), prompt
  following `research/AGENT.md` rules (evidence-traceable, cite comment IDs / finding IDs), write
  `Requirements/<driver>.md` (editable) and `texts.json`.
- Torque renders driver texts, FEAT, tour and Nordi intro from `texts.json`; "regenerate" per driver.

### 4. Finish
- Verify in Rowboat (Torque + Concept 3D), README (`demo/visu/README.md`), PR #7 body, board (log, C1/C2).
