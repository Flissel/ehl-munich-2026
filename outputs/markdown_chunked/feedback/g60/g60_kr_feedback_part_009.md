- Signal types: complaint, unknown, unmet_need

Classifications:

- Defect (complaint): Drivetrain : Malfunction / Drivetrain / Malfunction
- Difficult to Use (complaint): Exterior : Size not user friendly / Exterior / Size not user friendly
- Wants (unmet_need): Exterior rearview mirror : Customer request: function / Exterior rearview mirror / Customer request: function
- Wants (unmet_need): Exterior rearview mirror : Customer request: usability / Exterior rearview mirror / Customer request: usability
- Wants (unmet_need): Remote controlled parking : Customer request: function / Remote controlled parking / Customer request: function
- Wants (unmet_need): Remote controlled parking : Customer request: usability / Remote controlled parking / Customer request: usability
- Difficult to Use (complaint): Remote controlled parking : Not user-friendly / Remote controlled parking / Not user-friendly
- Wants (unmet_need): Space / spatial impression : Customer request: space / spatial impression / Space / spatial impression / Customer request: space / spatial impression
- unknown_feedback_type (unknown): no_class_found / no_class_found

Customer comment:

> 1. i paid extra for the remote parking option, but it often refuses to work. out of 10 attempts it seems to fail about half the time. especially in tight spaces it just won't allow remote parking at all, whether that's because of a sensor error or something else. honestly, i'd like to get my money back for this feature.

2. the body size is bigger than a mercedes-benz e-class or an audi a6, which makes it inconvenient when trying to park or drive through narrow streets. if the body is that large, the cabin should feel more spacious, but the interior doesn't really seem any bigger.

3. the hazard light button is a touch type, so you can't easily tell if it has actually been pressed. when you're in a rush, it's hard to switch it on, which raises the chance of an accident.

4. the bsi engine oil change interval is too long. i'd prefer replacing it every year or at around 15,000 km, but they set it at 20,000 km. trying to save money like that just seems like it will hurt people's impression of how durable the car is.

5. as soon as you approach the vehicle, the side mirrors fold out, which makes it awkward to squeeze between cars in a cramped parking lot. it would be better if the mirrors only opened when the door is actually opened or once the driver gets in.
