### G60-0695

- Source: Source A
- Vehicle: G60
- Market: US
- Engine type: BEVE
- Feedback types: Defect, Difficult to Use, Likes, unknown_feedback_type
- Signal types: complaint, praise, unknown

Classifications:

- Likes (praise): Anti-theft alarm system : Like: function / Anti-theft alarm system / Like: function
- Defect (complaint): Anti-theft alarm system : Malfunction / Anti-theft alarm system / Malfunction
- Likes (praise): Audio mode, sound : Like: sound / Audio mode, sound / Like: sound
- Difficult to Use (complaint): Automatic-hold : Not user-friendly / Automatic-hold / Not user-friendly
- Likes (praise): Drivetrain : Like: performance / Drivetrain / Like: performance
- Likes (praise): Interior mirror, garage door opener : Like: function / Interior mirror, garage door opener / Like: function
- Likes (praise): Pedals, operate : Like: function / Pedals, operate / Like: function
- Difficult to Use (complaint): Seating, ventilate / heat : Not user-friendly / Seating, ventilate / heat / Not user-friendly
- unknown_feedback_type (unknown): no_class_found / no_class_found

Customer comment:

> i'm pleased overall but not as thrilled as i thought i would be. a few small tweaks would really help.

air conditioned seats: i can tell the car not to turn on seat heat by default, but i can't do the same for the cooling. having a cold butt is uncomfortable for me, i don't want it at all and end up switching it off every single drive. on hot days that makes me dislike the car a bit.

- garage door openers: with such a smart car, it should use geofencing to automatically open gates and garage doors as you arrive. my old model s did that and it was extremely convenient.

- alarm: again with geofencing, the car should be able to stay unlocked and disarmed automatically when parked at home. not for everyone, but it would be easy to add as a menu option so in a safe garage you don't risk setting off the alarm or hunting for a key to open the trunk.

one-pedal driving: i use aggressive energy recovery and really like it, but i'd prefer if it brought the car all the way to a stop instead of continuing to creep.

auto hold: when auto hold releases in traffic or at lights, even with a very gentle press on the pedal the car snaps out of the hold and lurches slightly. it's annoying and should be much smoother.

on the positive side, the audio system and in-car phone are excellent. i especially value the speakerphone performance.

for an ev it truly still handles like a bmw, and i'm glad for that.
