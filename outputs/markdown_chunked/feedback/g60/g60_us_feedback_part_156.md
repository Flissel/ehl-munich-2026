### G60-2116

- Source: Source B
- Vehicle: G60
- Market: US
- Engine type: ICE
- Feedback types: Difficult to Use
- Signal types: complaint

Classifications:

- Difficult to Use (complaint): Remote Engine Start (Vehicle Key ) : Not user-friendly / Remote Engine Start (Vehicle Key ) / Not user-friendly

Customer comment:

> Customer stated he assumed the vehicle could be started remotely using the phone or key but was unsure how to do it. Writer asked if customer was currently with the vehicle and verified he was inside the parked car. Writer advised that the remote engine start feature must first be enabled within the vehicle settings. Writer directed customer to press the fan icon at the bottom of the main screen to access the climate control menu. Writer instructed customer to select pre-conditioning on the left side and then choose the remote engine start option. Writer confirmed customer needed to tap start engine under climate control to switch the feature on. Customer confirmed the setting was now active. Writer then told customer to open the My BMW app on his phone. When the remote engine start tile did not appear right away, writer asked customer to fully close and reopen the app. Customer confirmed he could now see the remote engine start function in the app. Writer further explained that the vehicle can also be started with the key fob by pressing the round lock button three times. Customer verified he understood how the system works. Customer successfully turned on the remote engine start in the car and learned to use both the mobile app and key fob methods to start the vehicle remotely.
