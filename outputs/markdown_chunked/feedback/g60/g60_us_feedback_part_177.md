### G60-2418

- Source: Source B
- Vehicle: G60
- Market: US
- Engine type: ICE
- Feedback types: Difficult to Use
- Signal types: complaint

Classifications:

- Difficult to Use (complaint): Remote Engine Start (Vehicle Key ) : Not user-friendly / Remote Engine Start (Vehicle Key ) / Not user-friendly

Customer comment:

> Customer stated they were not able to find where the remote start feature is located. Writer stated that remote start must be enabled through the climate control settings under the preconditioning menu in the vehicle. Writer stated detailed steps for using remote start with the key fob, which requires three quick presses of the BMW logo button, as well as how to start it through the app using the fan icon. Writer offered to provide further assistance via video chat if needed when the customer is with the vehicle.
