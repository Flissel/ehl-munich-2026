### G60-2607

- Source: Source A
- Vehicle: G60
- Market: US
- Engine type: BEVE
- Feedback types: Defect, Difficult to Use, Likes, Wants, unknown_feedback_type
- Signal types: complaint, praise, unknown, unmet_need

Classifications:

- Difficult to Use (complaint): Charge high-voltage battery : Too slow / Charge high-voltage battery / Too slow
- Likes (praise): Handling / Riding : Like: function / Handling / Riding / Like: function
- Wants (unmet_need): Lane departure warning : Customer request: function / Lane departure warning / Customer request: function
- Defect (complaint): Route optimized for charging : Malfunction / Route optimized for charging / Malfunction
- unknown_feedback_type (unknown): no_class_found / no_class_found

Customer comment:

> i really enjoy how the car rides. but bmw has a lot of room to improve when it comes to tech and charging. on the tech side, bmw should really take a look at what hyundai offers, especially since their cars cost a lot less. lane assist needs to be much better, keeping the car truly centered in the lane and handling corners properly for the whole trip. the "cruise control" also needs an upgrade so it adjusts correctly for the following distance the driver selects, and can bring the car all the way to a stop when the car in front stops. the driver alerts like lane departure and car proximity warnings also need to function more reliably.

for charging, bmw should finish up a deal with tesla so bmw owners can use the tesla fast chargers, or else team up with other brands in a joint venture to build a competing fast charging network. right now the non-tesla chargers are not dependable, and even the ones that show up on the bmw map sometimes are not actually there.
