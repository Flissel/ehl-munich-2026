### G60-3472

- Source: Source B
- Vehicle: G60
- Market: US
- Engine type: PHEV
- Feedback types: Difficult to Use
- Signal types: complaint

Classifications:

- Difficult to Use (complaint): Drivetrain : Not user-friendly / Drivetrain / Not user-friendly

Customer comment:

> Customer stated the car was sold to them as a hybrid, but in actual use it runs purely on electric power for an initial number of miles and then, once that range is depleted, which happens within the same day if they drive more than about 30 miles, it switches over to using only gas. Writer advised that this model is indeed a hybrid and includes a specific hybrid mode. Writer advised that in the Driving settings the drive mode can be set to hybrid drive so the vehicle operates in hybrid drive for the current journey. Writer advised that when navigation is active, the anticipatory hybrid mode engages to manage electric energy optimally, so the vehicle can drive electrically along the navigation route in city areas and close to the destination. Writer advised that if the high-voltage battery has sufficient charge, further parts of the route will be allocated to electric driving.
