- Source: Source B

- Engine type: BEVE
- Feedback types: Difficult to Use
- Signal types: complaint

Classifications:

- Difficult to Use (complaint): Parking Assistant : Not user-friendly / Parking Assistant / Not user-friendly

Customer comment:

> Customer reported he relies heavily on the recorded path function because his driveway sits at a strange angle. Customer indicated the feature only works roughly 50 percent of the time. Customer commented it feels like he has to position the car exactly right for it to trigger, which is hard. Writer asked if the system lets him start the maneuver at all or if it cancels itself after beginning. Customer replied it never gives an option to start, it only shows an option to create a new path.
